# Contributing

Thanks for helping. Bug reports, fixes and improvements are welcome as GitHub
issues and pull requests. Please run `swift test` and `(cd server && npm test)`
before sending a pull request.

## Licence of contributions (the one rule that matters)

SameSofa is licensed under MIT-0 (see LICENSE). Contributions are accepted under
the same licence: inbound = outbound. There is no contributor licence agreement.

By submitting a contribution you confirm that you wrote it, or otherwise have
the right to submit it, and that you agree to it being distributed under MIT-0
as part of SameSofa. Don't submit code or files copied from somewhere else
unless their licence allows that; say where they came from and keep their
licence notice (and add them to THIRD-PARTY-NOTICES.md).
