# Disclaimer

Plain-English notes about what SameSofa is and isn't. The licence (LICENSE,
MIT-0) is what actually governs the software; this page doesn't change it.

**Provided as is.** SameSofa is free, open-source software provided as is,
without warranty of any kind and without support. Use it at your own risk.

**No hosted service.** The project doesn't run a service for you. The server
address in the source code (`wss://CHANGE-ME.example`) is a placeholder, not a
service. Whoever builds or sets up SameSofa runs their own room server (see the
README) and is responsible for it.

**Your files, your responsibility.** SameSofa is meant for watching your own
films with one other person. You are solely responsible for the files you share
and for having the right to share them with that person. SameSofa does nothing
to get around copy protection (DRM) and cannot open DRM-protected files.

**Camera and microphone.** They are used only for the call between the two of
you, which goes directly between the two Macs (peer to peer). The project
doesn't record or collect any audio, video, film or usage data. See *Privacy* in
the README for exactly what a room server and STUN/TURN servers can see.

**No affiliation.** SameSofa is an independent project. It isn't affiliated
with, endorsed by or connected to any streaming service, watch-party product or
company. Product names mentioned anywhere in the project are trademarks of their
respective owners.

**Security issues.** Please report them privately through GitHub's
*Report a vulnerability* button on the repository's Security tab (private
vulnerability reporting), or open an issue without exploit details if that
isn't available. This is a volunteer project: there is no guaranteed response
time.
